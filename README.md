## Idea

Turn $100 into the most money in 30 days by selling a small, measurable service an AI agent can actually deliver at scale: a $49 same-day Shopify speed fix. Slow stores lose sales every day, so the pain is real and the result is provable with before/after Lighthouse scores. The agent finds buyers on Fiverr, targets slow stores found via BuiltWith, spends the $100 on promoted gigs, automates the audit, and delivers in 2 hours, 24/7 — faster than any human freelancer. Each $49 fix is a chance to upsell $99/month monitoring, and profits are reinvested into more promotion, aiming for 30 sales by day 30. It is low-risk, repeatable, and uses marketplaces and tools that exist today.

## How to run

```sh
node main.ts
```

This writes the plan text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is 275 characters, deterministic, and requires no network.
